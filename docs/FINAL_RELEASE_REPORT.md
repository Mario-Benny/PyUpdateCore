# Final release report

PythonUpdateCore 1.0.0 is prepared as an MIT-licensed Windows update SDK. Source and Windows x64 SDK ZIPs are generated under `release/1.0.0` with SHA-256 checksums. The SDK excludes the experimental Bootstrapper from the Windows binary package and retains it only in the source distribution.

No Git repository, remote, tag, online Release, ClassTool source, or third-party installer was modified during this release preparation.
