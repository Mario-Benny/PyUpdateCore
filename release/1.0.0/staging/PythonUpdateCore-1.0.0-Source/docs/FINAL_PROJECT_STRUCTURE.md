# Final project structure

- `updater.py`: CLI and stdio server entry point.
- `update_core/`: configuration, providers, downloader, verification, storage, IPC and Windows adapters.
- `examples/`: Python, Java, C++ and configuration examples.
- `tests/`: automated core regression suite.
- `docs/`: architecture, security, build, protocol, configuration and release documents.
- `experimental/`: non-production self-update research.
- `release/1.0.0/`: locally generated source and Windows SDK release artifacts.
